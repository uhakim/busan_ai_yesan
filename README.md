# AI Club Settlement Helper

2026 AI 디지털 교사 동아리 정산을 쉽게 처리하기 위한 로컬 웹앱 기획 폴더.

목표는 선생님들이 영수증과 지출 정보를 쉽게 제출하고, 유하님이 마지막에 정산서 양식에 맞는 출력물을 자동 생성하는 것이다.

## Files

- `docs/DESIGN.md` - 전체 제품 설계와 화면 흐름
- `docs/FIELD_MAPPING.md` - 정산서 양식에 들어갈 필드 매핑
- `docs/CORELAB_REFERENCE_NOTES.md` - CORE LAB 사이트에서 참고할 만한 기능 분석
- `references/정산서_이름_학교_동아리명.pptx` - Padlet에서 내려받은 정산서 원본 양식
- `references/corelab-settlement-report.xlsx` - CORE LAB 사이트 정산보고서 다운로드 샘플

## First Build Target

1차 버전은 외부 서버 없이 로컬 브라우저에서 실행하는 단일 웹앱으로 만든다.

- 선생님 제출 화면
- 관리자 확인 화면
- 예산 현황 대시보드
- 최종 정산서 인쇄/PDF 출력 화면
- JSON 내보내기/가져오기

개인정보와 금융정보가 포함되므로 초기 버전은 공개 웹 배포를 피하고 로컬 실행을 기본값으로 둔다.

## 협의회비 서버 저장과 HWPX 출력 (2026-10-10)

- 관리자의 일반 지출 입력·수정을 Supabase expenses/expense_files/private receipts에 저장한다. 로컬 모드는 기존 브라우저 저장을 유지한다.
- 업무협의회비에 시작·종료 시간, 장소, 주제, 내용, 참석자·불참자를 입력한다. 참석자 식비 1인 30,000원 이내를 검증한다.
- 기존 DB 마이그레이션 없이 협의 정보는 notes에 버전 표식과 JSON으로 보관하고, 화면에서는 일반 비고와 협의 정보를 분리한다. 기존 문자열 비고와 회원 AI 구독료 제출 방식은 그대로 읽는다.
- 협의록 첨부 칸은 HWPX도 지원한다. 최종 출력의 **정산서 HWPX 다운로드**는 표지, 총괄표, 예산별 세부내역, 협의록, 이미지 증빙을 하나의 한글 문서로 생성한다.
- HWPX 협의록은 글꼴·스타일 참조를 재배정하여 표와 사진을 합친다. 출력 페이지는 A4로 통일하므로 다른 용지 규격·특수 문서의 배치는 원본과 달라질 수 있다.
- PDF 증빙은 각 페이지를 PNG로 렌더링해 HWPX에 삽입한다. 업로드한 원본은 변경하지 않는다. 첨부 원본 다운로드 실패 시 누락된 상태로 출력하지 않고 오류를 표시한다.
- 다른 회원 소유 지출을 관리자가 수정할 때 소유자·지급 상태를 유지한다. 첨부 교체는 api/admin-expense-upload.js에서 활성 관리자와 같은 동아리 지출을 확인한 뒤 원래 소유자 경로의 업로드 토큰을 발급한다. 기존 서버 전용 SUPABASE_SERVICE_ROLE_KEY를 사용한다.
- 실패한 새 지출과 임시 업로드는 정리를 시도한다. 정리에 실패하면 중복 제출 전 목록 확인을 요청한다. 기존 첨부는 새 내용 저장 후 정리한다.

검증: app 폴더에서 npm test와 npm run build. 식비·시간 검증, 기존 비고 호환, 저장 실패 시 원본 보존, HWPX 합계·스타일·이미지 보존을 확인한다. 실제 10/7 협의록과 영수증을 합친 출력 예시는 Mac 한글에서 열림 및 표·명단·사진 배치를 확인했다. 운영 계정으로 로그인한 실제 저장 확인은 별도로 필요하다.

## 원본 양식 PPTX 출력 (2026-10-11)

최종 출력 탭의 **원본 양식 PPTX 다운로드**는 `references/정산서_이름_학교_동아리명.pptx`의 복사본(`app/public/templates/settlement.pptx`)에 등록 내용을 채운다. 기존 HWPX 다운로드는 유지한다.

- 원본 세로 용지, 로고, 마스터, 표 위치·열 너비·병합 셀을 보존한다. 표지·총괄표·세부내역은 PowerPoint에서 편집할 수 있다. 최종 제출 안내에 따라 파란 작성 안내 문구와 예시를 제거한다.
- 항목별 지출은 원본 표의 합계 행 위에 필요한 행을 추가하여 한 표에 모두 표시한다. 합계는 표 맨 아래에 한 번 표시한다. 긴 설명은 행 높이를 늘리고 증빙 제목을 아래로 옮긴다.
- 첨부한 PNG/JPG와 모든 PDF 페이지를 포함한다. 첫 이미지 증빙은 양식 내 증빙 칸과 확대 페이지에 넣는다. 이미지는 원본 비율로 표시하며 영수증을 자르거나 내용을 수정하지 않는다.
- 현재 사용한 7행·4열 협의록 HWPX는 참석자 표·본문·사진을 읽어 페이지 이미지로 넣는다. 이는 한글 프로그램의 인쇄 렌더링과 글꼴·여백이 완전히 같지는 않은 미리보기이며, 편집할 원본 HWPX는 기존 첨부로 유지된다. 다른 협의록 양식/여러 구역은 PDF를 함께 등록해야 한다. 원본을 읽을 수 없거나 지원하지 않는 첨부가 있으면 누락된 파일을 내려주지 않고 오류를 표시한다.
- 다운로드는 현재 로그인한 연구회의 최신 서버 기록을 읽으며 저장 상태·지급 여부·첨부 원본을 바꾸지 않는다. 학교·학교장·주소·연락처 등 미등록 정보와 보고일·직인란은 빈칸으로 남긴다.

검증: `npm test` 16개 및 `npm run build`. 두 연구회 실제 기록과 첨부로 PPTX를 생성해 원본과 비교하고 PowerPoint 열기를 확인했다. 페이지 복제 시 발표자 메모의 역참조를 제거하여 복구 경고를 방지한다.
